# 225W 功耗与性能诊断相关文件整理

## 重要声明
**本方案及相关文件仅涉及软件层面的功耗与性能调校验证，不会对设备的 BIOS 进行任何修改或写入。** 请在参考时注意此安全说明。

## 文件清单说明

### 1. 核心诊断报告
- `ROG_G635LX_GPU诊断报告.html`: 完整的 GPU 诊断分析报告。
- `ROG_G635LX_调校执行报告.html`: 详细记录了调校过程及执行结果。
- `ROG_G635LX_225W复试结果.html`: 针对 225W 方案的复试验证结果。

### 2. 验证与证据
- `GPU超频测试证据.zip`: 包含 GPU 超频测试过程中的原始截图与数据。
- `225W新路线重启前证据_20261019.zip`: 重启前的系统状态备份证据。
- `ROG_G635LX_调校证据.zip`: 调校过程中的关键数据记录。

### 3. 详细记录与清单
- `GPU调校基线与操作记录.txt`: 记录了所有操作的初始基线。
- `225W尝试准备_备份清单.csv`: 备份文件的详细索引。
- `225W非官方方案核查证据清单.csv`: 非官方方案核查的相关证据索引。

## 使用建议
建议先阅读 `ROG_G635LX_GPU诊断报告.html` 以了解整体背景，再结合 `GPU调校基线与操作记录.txt` 进行具体参数的对比分析。
